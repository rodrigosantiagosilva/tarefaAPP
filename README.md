tarefaAPP
Sobre o projeto

Aplicação de gerenciamento de tarefas que permite organizar atividades do dia a dia de forma simples.

  Funcionalidades
Criar tarefas
Listar tarefas
Editar tarefas
Remover tarefas
Marcar tarefas como concluídas ou favoritas
Filtrar tarefas
  Tecnologias utilizadas
Vue.js / Ionic
JavaScript ou TypeScript
HTML
CSS

    Como executar
  Clonar o repositório
git clone https://github.com/rodrigosantiagosilva/tarefaAPP.git
  Entrar na pasta
cd tarefaAPP
  Instalar dependências
npm install
  Rodar o projeto
npm run dev
